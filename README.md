# 🎮 친구들 공 레이스! 누가 당번일까? (Friends Ball Race)

> **HTML5 Canvas, CSS3, Vanilla JavaScript로 제작된 긴장감 넘치는 당번 정하기 공 레이스 게임!**  
> 친구들의 이름을 입력하고 레이스를 시작하면, 각자의 귀여운 캐릭터 공이 다이내믹한 4티어 슬라롬 코스와 핀볼 숲을 질주합니다.  
> **1등으로 결승선에 가장 먼저 도착한 친구가 오늘의 당번으로 선정됩니다!**

## ✨ 주요 특징 (Key Features)

1. **완벽한 원형 3D 캐릭터 공**
   - 찌그러짐 없이 완벽한 구형(동그라미) 디자인과 실시간 3D 원형 하이라이트 & 귀여운 표정(윙크, 반짝이, 고양이 입 등) 및 액세서리 장착.
   - 레이스 중 1등 선두에게는 실시간 황금 왕관(👑)과 네온 아우라 링이 부여되어 실시간 선두 경쟁을 한눈에 볼 수 있습니다.

2. **예측 불허의 4티어 와이드 슬라롬 & 핀볼 코스**
   - **Zone 0**: 좌우 대칭 분산 핀을 통한 100% 공평한 출발 게이트.
   - **Tier 1 ~ 4**: 가로 600px을 가로지르는 4단 지그재그 슬라롬 트랙과 가속 부스터 패드(`>>>`).
   - **회전 스피너 & 스위퍼**: 공의 궤적을 섞어주고 하방으로 가속시키는 3개의 회전 윈드밀.
   - **핀볼 플링코 포레스트**: 16개의 고탄성 네온 범퍼와 좌우로 흔들리는 무빙 범퍼로 매 경기마다 수십 번의 역전 발생.
   - **스플릿 루트 & 피니시 룰렛**: 결승선 바로 앞에서 선두를 견제하는 삼각 범퍼로 마지막 0.5초까지 결과를 알 수 없는 짜릿한 승부!

3. **100% 무결점 끼임 방지 엔진 (Auto-Rescue Watchdog)**
   - 장애물 사이에 끼이거나 갇히지 않도록 3단계 자동 감지 & 탈출 시스템 내장.

4. **웹 오디오 사운드 합성기 (Web Audio API)**
   - 외부 음원 파일 의존 없이 카운트다운 비프음, 충돌 바운스, 부스터 사운드, 1등 축하 차임 및 경기 종료 팡파르 합성 재생.

5. **실시간 라이브 순위표 & 승리자 축하 모달**
   - 레이스 실시간 Y좌표 기반 순위 변동 및 화려한 컨페티(꽃가루) 축하 세레머니.

## 🛠️ 기술 스택 (Tech Stack)

- **Markup**: HTML5 (시맨틱 구조)
- **Styling**: CSS3 (Vanilla CSS, 글래스모피즘, 반응형 모바일/태블릿/데스크톱 대응)
- **Programming**: Vanilla JavaScript (ES6+, 순수 순수 브라우저 API, 외부 라이브러리 Zero)
- **Graphics**: HTML5 Canvas 2D API (60FPS 물리 렌더링)
- **Audio**: Web Audio API (내장 오디오 신시사이저)

## 🚀 실행 방법 (How to Run)

별도의 Node.js 설치나 빌드 과정 없이, 브라우저에서 `index.html`을 더블클릭하면 즉시 실행됩니다!
